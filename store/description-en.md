# Word Ladder — Store Submission Materials

## Short description (CrazyGames / GameDistribution / itch.io)

Climb from COLD to WARM one letter at a time — every step must be a real
word. Daily challenge, endless mode and a smart keyboard that only offers
letters that keep you on a valid path. A classic Lewis Carroll word puzzle.

## Details

- Genre: Puzzle / Word / Casual
- Controls: Tap a letter of your current word, then pick a highlighted
  replacement — only letters that form valid words are shown. Desktop: type
  the full 4-letter word, Backspace to undo, H for hint.
- Features: Daily Challenge (3 seeded puzzles), Endless mode (Easy 3 /
  Medium 4 / Hard 5+ step par), hint system, undo, PERFECT x2 bonus for
  matching the shortest path, streak & best saved locally, mute button.
- Visual: ink-on-paper ladder with rising card animation, 1,400+ curated
  common 4-letter words, graph connectivity verified (every word reachable).
- Tech: Vanilla JavaScript, DOM + CSS, WebAudio. Single-file HTML5, no
  external assets, no tracking, no external links.
